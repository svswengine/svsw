# Contributing

svsw is open source under Apache-2.0 (see [LICENSE](LICENSE)). It is
closed to external contributions while the maintainer shapes the engine.

Pull requests are closed without review for now. An automated action will do
this once CI exists (spec S00); until then, expect a manual close with a
pointer to this file.

Bug reports and reproduction cases are welcome via issues.

When contributions open, inbound licensing is Apache-2.0 ("inbound =
outbound"), with a Developer Certificate of Origin (DCO) sign-off required
on every commit. The sign-off mechanism will be announced in this file when
that happens.
