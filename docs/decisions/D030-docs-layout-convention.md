# D30: Documentation layout convention

Status: current
Date: 2026-07

Every documentation markdown file lives under `docs/` in a subdirectory:
`docs/specs`, `docs/plans`, and more as content arrives. `docs/README.md` is
the router. Project style guides are one exception and sit at the top
level of `docs/` beside it: `ODIN_STYLE.md` now, with Luau and Go style
guides joining later as those languages arrive. The rule applies to both the
`svsw` and `course` repositories. Amended 2026-07-30, settled with the
maintainer: `docs/VENDOR.md`, the S01 vendoring manifest, is a second
top-level exception.
